**Dosya:**
- `database.py` (YENİ - 350 satır)

**Tablolar:**
```sql
CREATE TABLE plugins (
    id INTEGER PRIMARY KEY,
    slug TEXT UNIQUE,
    name TEXT,
    version TEXT,
    last_scanned TIMESTAMP
);

CREATE TABLE scans (
    id INTEGER PRIMARY KEY,
    plugin_id INTEGER,
    scan_timestamp TIMESTAMP,
    status TEXT,  -- 'clean', 'vulnerable', 'error'
    vulnerabilities_count INTEGER,
    taint_flows_count INTEGER,
    ai_calls_count INTEGER
);

CREATE TABLE vulnerabilities (
    id INTEGER PRIMARY KEY,
    scan_id INTEGER,
    plugin_slug TEXT,
    type TEXT,  -- 'SQL Injection', 'XSS', etc.
    severity TEXT,  -- 'Critical', 'High', etc.
    cvss_score REAL,
    file_path TEXT,
    line_number INTEGER,
    description TEXT,
    poc_command TEXT
);

CREATE TABLE api_usage (
    id INTEGER PRIMARY KEY,
    timestamp TIMESTAMP,
    provider TEXT,  -- 'github', 'gemini'
    model TEXT,
    tokens_used INTEGER,
    cost_usd REAL
);
```

**API:**
```python
from database import get_db
db = get_db()

# Plugin tarandı mı?
if db.is_plugin_scanned("plugin-slug", "1.0.0"):
    print("Zaten tarandı")

# Tarama kaydet
scan_id = db.add_plugin_scan(
    slug="plugin-slug",
    name="Plugin Name",
    version="1.0.0",
    status="vulnerable",
    vulns_count=2,
    taint_flows=5,
    ai_calls=3
)

# Zafiyet kaydet
db.add_vulnerability(scan_id, "plugin-slug", {
    "type": "SQL Injection",
    "severity": "High",
    "cvss_score": 8.5,
    "file": "/path/to/file.php",
    "line": 42
})

# İstatistikler
stats = db.get_stats()
print(stats)  # {'total_plugins_scanned': 150, 'total_vulnerabilities_found': 5, ...}

# VACUUM (boyutu küçült)
db.vacuum()

# Boyut kontrolü
print(f"{db.get_database_size():.1f}MB")
```

**Kullanım:**
```python
from rate_limiter import get_rate_limiter
limiter = get_rate_limiter()

# Rate limit ile API çağrısı
def call_github_api():
    limiter.wait_if_needed("github")
    try:
        response = api_call()
        limiter.record_success("github")
        return response
    except Exception as e:
        limiter.record_failure("github")
        raise

# Circuit breaker kontrolü
if not limiter.is_service_available("github"):
    print("Servis devre dışı!")
```

**Yapılandırma:**
```python
RATE_LIMITS = {
    "github": {

        "backoff_base": 2.0,
        "max_backoff": 60.0,
        "jitter": 0.25,
        "circuit_breaker_threshold": 10,
        "circuit_breaker_timeout": 300  # 5dk
    }
}
```
